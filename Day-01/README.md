# Day 1 – Docker Fundamentals

## Objective
Understand Docker fundamentals, verify Docker installation, and execute my first Docker container.

## Topics Covered
- Introduction to Docker
- Containerization
- Docker Images
- Docker Containers
- Docker Hub
- Docker Engine and Docker CLI
- Containers vs Virtual Machines

## Practical Tasks
- Verified Docker installation.
- Inspected Docker Engine.
- Checked Docker service status.
- Executed the Hello World container.
- Listed Docker images.
- Listed running and stopped containers.
- Explored container IDs and image IDs.

## Key Learnings
- An image is a template used to create containers.
- A container is an instance of an image.
- `docker ps` displays running containers.
- `docker ps -a` displays all containers.
- `docker run` creates and starts a container.
