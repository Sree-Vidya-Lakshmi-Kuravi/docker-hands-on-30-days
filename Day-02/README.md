# Day 2 – Docker Container Lifecycle Management

## Objective
Learn to create, start, stop, restart, pause, unpause and remove Docker containers.

## Topics Covered
- Container lifecycle
- Detached mode (`-d`)
- Interactive mode (`-it`)
- Container naming
- Container stopping and restarting
- Container removal

## Commands Practiced
- docker run
- docker start
- docker stop
- docker restart
- docker pause
- docker unpause
- docker rm
- docker rm -f
- docker logs
- docker ps

## Practical Tasks
- Created an Nginx container.
- Practiced detached mode.
- Created an interactive Ubuntu container.
- Started and stopped existing containers.
- Restarted containers.
- Paused and resumed containers.
- Removed stopped and running containers.
