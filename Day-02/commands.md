## Docker Container Management Commands

## Container Lifecycle Commands

#### 1. docker run
- Creates and starts a new container from a specified image. 
- If the image is not available locally, Docker will automatically pull it from the configured registry (e.g., Docker Hub).
- Syntax: docker run [OPTIONS] IMAGE [COMMAND] [ARG...]
Common Options:
-d: Run container in detached mode (in the background).
-p: Publish a container's port(s) to the host (host_port:container_port).
--name: Assign a custom name to the container.
- Example: docker run -d --name my-nginx -p 8080:80 nginx
Starts a new Nginx container named my-nginx in the background, mapping port 8080 on the host to port 80 inside the container.

#### 2. docker start
- Starts one or more stopped containers without creating a new one.
- Syntax: docker start [OPTIONS] CONTAINER [CONTAINER...]
- Example: docker start my-nginx
Starts the previously stopped container named my-nginx.

#### 3. docker stop
- Gracefully stops one or more running containers by sending a SIGTERM signal, allowing the process time to clean up before sending a SIGKILL if it doesn't stop within a grace period (default is 10 seconds).
- Syntax: docker stop [OPTIONS] CONTAINER [CONTAINER...]
- Example: docker stop my-nginx
Gracefully stops the running container named my-nginx.

#### 4. docker restart
- Restarts one or more running or stopped containers (essentially performs a stop followed by a start).
- Syntax: docker restart [OPTIONS] CONTAINER [CONTAINER...]
- Example: docker restart my-nginx
Restarts the my-nginx container.

#### 5. docker pause
- Suspends all processes within one or more running containers using cgroups freezer. 
- The container remains in memory, and its state is preserved, but it consumes no CPU cycles.
- Syntax: docker pause CONTAINER [CONTAINER...]
- Example: docker pause my-nginx
Freezes all running processes inside my-nginx.

#### 6. docker unpause
- Resumes all suspended processes within one or more paused containers.
- Syntax: docker unpause CONTAINER [CONTAINER...]
- Example: docker unpause my-nginx
Resumes execution of the paused my-nginx container.

## Container Removal Commands
#### 7. docker rm
- Removes one or more stopped containers. 
- Docker will throw an error if you attempt to remove a container that is currently running.
- Syntax: docker rm [OPTIONS] CONTAINER [CONTAINER...]
- Example: docker rm my-nginx
Deletes the stopped container named my-nginx.

#### 8. docker rm -f
- Force-removes one or more containers, even if they are currently running (sends a SIGKILL signal to stop them immediately before removal).
- Syntax: docker rm -f CONTAINER [CONTAINER...]
- Example: docker rm -f my-nginx
Immediately kills and deletes the running my-nginx container.

## Monitoring & Inspection Commands
#### 9. docker logs
- Fetches the STDOUT and STDERR logs generated by a container.
- Syntax: docker logs [OPTIONS] CONTAINER
- Common Options:
    -f: Follow log output in real time (similar to tail -f).
    --tail N: Show only the last N lines of logs.
- Example: docker logs -f --tail 50 my-nginx
Displays the last 50 lines of logs for my-nginx and continues streaming new logs.

#### 10. docker ps
- Lists all currently running containers, displaying details such as Container ID, Image, Command, Creation time, Status, Ports, and Names.
- Syntax: docker ps [OPTIONS]
- Example: docker ps
Outputs a table of all active containers currently running on the system.

#### 11. docker ps -a
- Lists all containers on the system, including running, paused, exited, and created containers.
- Syntax: docker ps -a
- Example: docker ps -a
Outputs a complete list of every container on the host, regardless of its current state.
